Privacy policy

Effective October 24, 2026

This policy describes how Curious in 40 AutoTube, a personal desktop publishing tool operated by the Curious in 40 channel owner, handles information. It also covers this public information website. The application is for the owner's use; this website does not register users or collect Google credentials.

Google and YouTube data

With the owner's authorization, AutoTube uses Google OAuth and the YouTube Data API. It requests the youtube.readonly and youtube.upload permissions to identify and check the authorized channel, view available YouTube account and video information, and support video uploads. AutoTube never receives the Google account password.

The connection stores OAuth access and refresh tokens locally. Channel identifiers, channel titles, connection status and operational records may also be stored locally. The publishing workflow is being developed to send selected video files, titles, descriptions and publication settings to YouTube. YouTube hosts and processes uploaded content under its own policies.

Purpose and sharing

Data is used to connect the owner's channel, verify the destination, operate the publishing workflow and diagnose errors. AutoTube does not sell Google user data or use it for advertising. Google API data is not intentionally used to train generalized AI models.

Google receives API requests and uploads. The owner's AI-assisted workspace may process channel information, scripts and operational results to help operate the workflow. Separate AI media providers may process scripts or creative assets when used for production. OAuth tokens and client credentials must not be sent to those media providers or published on this website. Third-party services have their own privacy policies.

Storage, security and retention

Authorization credentials are stored in a local folder with restricted Windows permissions. They are excluded from the public website and its source repository. Local scripts, media and operational records remain on the owner's computer until removed. Credentials are retained while the connection is needed; this personal tool does not currently implement an automatic retention schedule.

Control, revocation and deletion

The owner can revoke AutoTube's Google access using Google Account third-party connections at any time. Revoking access prevents future authorized API access but does not erase files already stored locally. The owner can delete local credentials and records from the AutoTube workspace. Uploaded videos remain on YouTube until the owner removes them through YouTube Studio.

For questions or deletion assistance, contact the developer using the support address displayed on AutoTube's Google consent screen. The project channel is Curious in 40.

This website

This static website has no added analytics, advertising trackers, forms or sign-in system. It is hosted by GitHub Pages. GitHub may collect technical information, including visitor IP addresses, for security and service operation under the GitHub Privacy Statement. Following external links subjects you to the destination's policies.

Google API commitments

AutoTube's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. See also the Google Privacy Policy.

Changes

This page will be updated when the application's data handling changes. The effective date identifies the current version.
